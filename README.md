# One Last Message ❤️

A simple, responsive personal-message website.

## Run locally

Install dependencies:

npm install

Start the website:

npm start

The site will be available locally.

## Deployment

This project is a static website and can be deployed on Railway, Vercel, Netlify, GitHub Pages, or another static hosting service.

## Files

- index.html — Website structure
- style.css — Design and responsive layout
- script.js — Button interactions
- package.json — Node.js configuration
